Variables are references to objects. Python is dynamically typed, meaning you don't have to declare the data type; the variable automatically refers to the memory address of the object assigned to it

Real-World Examples

current_temperature = 25.5 (Storing a sensor reading).
user_name = "Alice" (Storing a profile name).
is_logged_in = True (Tracking a user's session status)

Variable Naming Rules

Names must start with a letter or an underscore.
They cannot start with a number.
They can only contain alphanumeric characters and underscores (A-z, 0-9, and _ ).
Variable names are case-sensitive (e.g., age, Age, and AGE are three different variables).
Python keywords (like if, def, while) cannot be used as variable names
